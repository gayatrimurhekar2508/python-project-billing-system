# Skill Nexis Internship – Week 3 OOP Assignment

## Overview
This repository contains the Week 3 Object-Oriented Programming assignments.

## Assignments
1. **Bank Account Class** – deposit, withdraw and display balance.
2. **Library Management System** – add/remove, issue/return and display books.
3. **Calculator with Exception Handling** – arithmetic operations, invalid input and division-by-zero handling.
4. **Mini Project: Billing System (OOP-based)** – Product and Bill classes, subtotal, 18% tax and final tabular bill.

## Files
- `01_BankAccount.java`
- `02_LibraryManagementSystem.java`
- `03_CalculatorWithExceptionHandling.java`
- `04_BillingSystemOOP.java`

## How to Run
Install Java JDK 8 or later.

Check:
```bash
java -version
javac -version
```

Run Assignment 1:
```bash
javac 01_BankAccount.java
java BankAccount
```

Run Assignment 2:
```bash
javac 02_LibraryManagementSystem.java
java LibraryManagementSystem
```

Run Assignment 3:
```bash
javac 03_CalculatorWithExceptionHandling.java
java CalculatorWithExceptionHandling
```

Run Mini Project:
```bash
javac 04_BillingSystemOOP.java
java BillingSystemOOP
```
